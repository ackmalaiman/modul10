


1. AJAX adalah teknik yang memungkinkan browser mengirim dan menerima data dari server tanpa harus memuat ulang seluruh halaman. Cara kerjanya yaitu JavaScript mengirim permintaan ke server, kemudian server memproses data dan mengirimkan hasilnya kembali untuk ditampilkan di halaman web



2. Contohnya Google Maps, ketika pengguna mencari lokasi atau menggeser peta, informasi akan diperbarui tanpa perlu memuat ulang seluruh halaman. Dengan begitu, pengguna bisa menggunakan website dengan lebih cepat dan nyaman
